# Theme collection

Monochrome, Catppuccin, Beige, Phosphor, Pixel, Dark Grey, Dark Cattpuccin, Fuji Dusk, Stillwater, Cold Front, Honeyveil, Teigu, Tideglass, Cyanframe, ViegPhunt and Serashell.

These are the desktop profiles in the original Rice Studio collection. Main is created locally during installation. The bundle includes the main PC’s 29 Waybar styles, the Atif dock variant, and the Serashell native panel.

- Serashell by [YoruAkio](https://github.com/YoruAkio/Serashell). The adapted QML and upstream license are in the Serashell theme directory.
- ViegPhunt preset based on [ViegPhunt/Dotfiles](https://github.com/ViegPhunt/Dotfiles).
- Monochrome bar adapted from [HANCORE's Waybar themes](https://github.com/HANCORE-linux/waybar-themes).
- [Zunder](https://github.com/elyesghazel/zunder) 0.3.6 is bundled under its MIT license.
- Catppuccin colors from [Catppuccin](https://github.com/catppuccin/catppuccin). The bundled terminal license is in the terminal theme directory.
- Tideglass uses the existing Lone Wanderer animated wallpaper. Cyanframe uses the Tideglass still and a Bad Apple dashboard clip.
- Additional wallpapers and reference art are bundled from the original local themes. Their original licenses apply. The repository's code license does not relicense artwork.

The release uses per-install paths, the local audio/network services and the recipient's Main. Personal hardware bindings and account settings are outside the theme bundle.
